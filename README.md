# MOH Boot

Multiboot manager for Enigma2 receivers.

This repository carries the update files used by the plugin's Update screen:

- `version.json` - the newest version, its package name and checksum
- `enigma2-plugin-extensions-mohboot_<version>_all.ipk` - the package

The source code is kept private (`source.tar.gz.gpg` is an encrypted archive).
